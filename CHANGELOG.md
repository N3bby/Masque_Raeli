# Masque: Raeli 27.4
* Added support for World of Warcraft: Forever (Interface 16001).
* Updated skins to the current Masque skin API (`API_VERSION` 120001).
* Migrated the deprecated `AutoCastable`/`AutoCastShine` skin settings to Masque's `AutoCast_Frame`/`AutoCast_Corners` layers (no visual change).
* Prefer `C_AddOns.GetAddOnMetadata` over the removed global `GetAddOnMetadata`.
